# Security and privacy

The current controllers use a configured bonded Bluetooth peer, manual sessions and NEXT/PREV commands. The phone helper does not retrieve window contents. Neither app has internet, microphone, location, storage or notification permission. This is a prototype, not a hardened remote-management platform.

For a vulnerability, use GitHub's private vulnerability reporting for this repository if available. Otherwise open a minimal issue requesting a private reporting channel, without exploit details or personal logs. Never post pairing codes, Bluetooth addresses, debug endpoints, tokens or bugreports in public issues.

End the session or disable the phone Accessibility helper to stop dispatching input. Wireless debugging is for installation only and should be turned off afterwards. See setup for uninstall instructions.

Private installation signing keys are not published. CI/local development APKs use separate development keys and should be treated as experimental sideloads.
