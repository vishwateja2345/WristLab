# Project metadata template

Copy the metadata structure for an independent project, or use `python3 tools/new_project.py my-project --name "My Project" --kind watch-app` from the root for a compilable starter. Underscore folders are not registered projects.

Document purpose, source/build steps, supported devices, setup, start/stop/undo, permissions, battery behavior, validation and asset rights. See [the contribution steps](../README.md) and [metadata contract](../../docs/PROJECTS.md).
