# Paused expanded controls

Historical source snapshot for comments, reading, media, navigation and a contextual command menu. It was superseded by the simpler manual controller after usability regressions. It is **not part of any current APK, supported setup or CI build**. No working or battery-performance claim is made for this snapshot.

This code has broader Accessibility and input behavior than the current release. Review its manifests and assumptions before reusing any part. The original source archive had no standalone build entry point; this is an archival reference, not a drop-in replacement for apps/watch or apps/phone. The roadmap describes what would be needed to revisit it.

Do not re-enable it on someone's devices as part of normal setup. Private diagnostic logs, device coordinates/identifiers and the original signing key are not included.
